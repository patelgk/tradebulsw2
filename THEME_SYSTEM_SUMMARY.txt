🏗️ ARCHITECTURE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SYSTEM FLOW:
1. Page loads → Flash prevention script runs
2. Script reads localStorage for user preference
3. If preference is 'system', detect current system theme
4. Apply theme to DOM before rendering
5. React mounts and useTheme provides context
6. Components use theme context and CSS variables
7. System theme changes monitored in real-time
8. Theme changes persist to localStorage

CONTEXT STRUCTURE:
├─ theme: 'light' | 'dark'              (Current active theme)
├─ preference: 'system' | 'light' | 'dark' (User's choice)
├─ isDark: boolean                       (Shorthand helper)
├─ toggleTheme(): void                   (Quick light/dark toggle)
└─ setThemePreference(): void            (Set preference explicitly)

CSS ARCHITECTURE:
├─ CSS variables for all colors
├─ Dark theme as :root default
├─ Light theme via :root[data-theme="light"]
├─ Tailwind utilities for theme-aware classes
├─ Smooth 0.3s transitions on theme change
└─ Print styles for consistency
