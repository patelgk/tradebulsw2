HOW IT WORKS
================================================================================

INITIALIZATION (Once per app):
  1. App mounts
  2. useEffect runs
  3. Import clarity service dynamically
  4. Check VITE_CLARITY_PROJECT_ID exists
  5. Check user consent in localStorage
  6. Load clarity.ms script
  7. Configure data masking
  8. Set initialized flag (prevents re-runs)

PAGE VIEW TRACKING (On tab change):
  1. User clicks different tab
  2. activeTab state changes
  3. useEffect detects change
  4. Call trackPageView(activeTab)
  5. Clarity receives page_view event
  6. Dashboard updates in real-time

CUSTOM EVENTS (On specific actions):
  1. User triggers event (e.g., buys challenge)
  2. Call clarityService.trackEvent()
  3. Clarity receives custom event
  4. Dashboard records event
  5. Analytics updated
