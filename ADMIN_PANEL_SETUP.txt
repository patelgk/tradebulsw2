🔒 ACCESS CONTROL
═════════════════════════════════════════════════════════════════════════════

Access Rule: role === 'admin' OR role === 'super_admin'

Scenarios:
1. Unauthenticated user visits /admin/*
   → Redirected to /admin (login page)

2. Authenticated user (role='user' or 'partner') visits /admin/*
   → Shows "Access Denied" message
   → Button to go back to app

3. Authenticated admin user (role='admin' or 'super_admin') visits /admin/*
   → Renders AdminLayout with sidebar
   → Shows appropriate admin page

⚠️ IMPORTANT: Backend admin endpoints must verify role independently

Example Express middleware:
```typescript
app.use('/api/admin/*', (req, res, next) => {
  const user = req.user; // From auth middleware
  if (user.role !== 'admin' && user.role !== 'super_admin') {
    return res.status(403).json({ error: 'Admin access required' });
  }
  next();
});
```
