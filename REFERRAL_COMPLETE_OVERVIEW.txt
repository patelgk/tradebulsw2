HOW IT WORKS:
───────────────────────────────────────────────────────────────────────────────

1. REFERRAL CODE CAPTURE
   File: src/App.tsx (lines 4050-4070)
   
   When app loads:
   - Extracts ?ref=BHOPAL01 from URL
   - Validates with /api/referral/validate
   - Records click via /api/referral/click
   - Stores in localStorage

2. SIGNUP WITH REFERRAL
   File: src/App.tsx (line 342)
   
   When user signs up:
   - referralCode passed to backend
   - Backend: POST /api/auth/signup
   - Creates user with role='user'
   - Finds Partner by referralCode
   - Attaches: partnerId, partnerCode, referralSource
   - Saves user to database

3. ROLE VERIFICATION
   File: src/App.tsx (lines 5804-5825)
   
   After auth:
   - Loads full profile from server
   - Checks role from database
   - Sets activeTab to 'trade' (for user role)
   - Clears referralCode from localStorage
   - Shows trading dashboard

4. COMMISSION ON PURCHASE
   File: server.ts (lines 1095-1110)
   
   When user buys challenge:
   - Finds user.partnerId
   - Looks up Partner by ID
   - Calculates: (fee × commissionRate) / 100
   - Creates Commission record
   - Status: pending

5. PARTNER EARNINGS DISPLAY
   File: src/components/PartnerDashboard.tsx (lines 44-50)
   
   Partner views dashboard:
   - Loads all Referral records for partner
   - Counts clicks and signups
   - Displays earnings stats
   - Lists referred users

BACKEND ENDPOINTS:
───────────────────────────────────────────────────────────────────────────────

GET /api/referral/validate?code=BHOPAL01
├─ Response: { valid: true, partnerId: "...", partnerName: "..." }
└─ Validates referral code exists and partner is approved

POST /api/referral/click
├─ Body: { referralCode, partnerId, ip, userAgent, path }
└─ Records referral click in database

POST /api/auth/signup
├─ Body: { email, password, mobile, name, referralCode }
└─ Creates user account and attaches to partner

GET /api/users/:uid
├─ Response: { uid, email, role, partnerId, partnerCode, ... }
└─ Returns full user profile with referral info

POST /api/transactions
├─ Body: { userId, type: 'challenge_purchase', amount, ... }
└─ Processes transaction and creates commission

GET /api/partner/referrals?uid=USER_ID
├─ Response: [ { referralCode, type, userId, createdAt }, ... ]
└─ Returns all referrals for partner


DATA MODELS:
───────────────────────────────────────────────────────────────────────────────

USER:
├─ uid: unique identifier
├─ role: 'user' (for referred users)
├─ partnerId: partner's MongoDB ID
├─ partnerCode: partner's referral code
└─ referralSource: 'partner'

PARTNER:
├─ _id: MongoDB ID
├─ partnerName: "Bhopal Partners"
├─ referralCode: "BHOPAL01"
├─ status: "approved"
└─ commissionRate: 15

REFERRAL:
├─ referralCode: "BHOPAL01"
├─ partnerId: partner's ID
├─ type: "click" or "signup"
├─ userId: user ID (if signup)
└─ timestamps

COMMISSION:
├─ partnerId: partner's ID
├─ userId: user ID
├─ transactionId: purchase transaction ID
├─ challengeName: "30-Day Challenge"
├─ purchaseAmount: 5000
├─ commissionRate: 15
├─ commissionAmount: 750
└─ status: "pending" | "earned" | "paid"
