┌────────────────────────────────────────────────────────────────────────────────┐
│  MARKET HOURS LOGIC                                                            │
└────────────────────────────────────────────────────────────────────────────────┘

IST Timezone Calculation:
  Date.now() + 5.5 * 60 * 60 * 1000  →  Convert UTC to IST

Trading Hours:
  Monday-Friday (days 1-5):
    9:15 AM  →  555 minutes (9*60 + 15)
    3:30 PM  →  930 minutes (15*60 + 30)

Logic:
  return day >= 1 && day <= 5 && mins >= 555 && mins <= 930;

Override (for testing):
  TEST_MODE=true npm start       → Market always open
  ENABLE_MARKET_SIMULATOR=true   → Market always open

│  DEDUPLICATION EXAMPLE                                                         │
└────────────────────────────────────────────────────────────────────────────────┘

Without Deduplication:
  Client 1 → GET /api/chart/history → Dhan API (call 1)
  Client 2 → GET /api/chart/history → Dhan API (call 2)
  Client 3 → GET /api/chart/history → Dhan API (call 3)
  Client 4 → GET /api/chart/history → Dhan API (call 4)
  Client 5 → GET /api/chart/history → Dhan API (call 5)
  Result: 5 calls, rate limit exceeded, some fail with 429

With Deduplication (NEW):
  Client 1 → GET /api/chart/history → Dhan API (call 1)
  Client 2 → GET /api/chart/history → Wait for Client 1
  Client 3 → GET /api/chart/history → Wait for Client 1
  Client 4 → GET /api/chart/history → Wait for Client 1
  Client 5 → GET /api/chart/history → Wait for Client 1
  Result: 1 call, all succeed, 80% bandwidth saved
