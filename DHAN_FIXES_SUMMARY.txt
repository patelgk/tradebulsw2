ROOT CAUSES FIXED
─────────────────────────────────────────────────────────────────────────────

1. ✅ Index Price Zero-Validation (CRITICAL)
   Location: services/marketFeedManager.ts:922-930
   Issue: Missing validation allowed zero prices to overwrite valid data
   Fix: Added guard: if (indexPrice <= 0) return;
   Impact: Prevents stale/zero prices from corrupting market data

2. ✅ Market Hour Detection (CRITICAL)
   Location: services/marketFeedManager.ts:1383-1390
   Issue: Market was open 24/7 instead of 9:15 AM - 3:30 PM IST Mon-Fri
   Fix: Changed from "day >= 0 && mins >= 0 && mins <= 1440" 
        to "day >= 1 && day <= 5 && mins >= 555 && mins <= 930"
   Impact: Restricts price broadcasts to actual trading hours

3. ✅ PrevClose Initialization (HIGH)
   Location: services/marketFeedManager.ts:227-236
   Issue: prevClose initialized to 0, causing Infinity in calculations
   Fix: Changed prevClose: 0 to prevClose: undefined
   Impact: Prevents division by zero in percentage calculations

4. ✅ Chart Event Ordering (HIGH)
   Location: services/marketFeedManager.ts:880-905, 995-1015
   Issue: setImmediate() deferred candle updates 1-10ms, causing out-of-order events
   Fix: Removed setImmediate() wrappers, process candles immediately
   Impact: Chart updates emit in correct order, no data corruption

5. ✅ Chart API Error Handling (HIGH)
   Location: server.ts:145-240
   Issue: All errors returned as 502, proper status codes not returned
   Fix: Added specific error handling for 400/401/429/503 status codes
   Impact: Clients receive correct error codes for proper error handling

6. ✅ Chart History Rate Limiting (HIGH)
   Location: server.ts:75, 242-290
   Issue: No request deduplication; concurrent requests hammered Dhan API
   Issue: Timeout too short (10s) for historical data fetches
   Fix: Added request deduplication map + increased timeout to 30s
   Impact: 5 concurrent requests now use 1 Dhan API call

KNOWN LIMITATIONS & NOTES
─────────────────────────────────────────────────────────────────────────────

1. Market Hours Restriction:
   - Trading hours: Mon-Fri 9:15 AM to 3:30 PM IST only
   - Outside hours: isMarketOpen = false, prices don't update
   - Override with TEST_MODE=true or ENABLE_MARKET_SIMULATOR=true

2. Rate Limiting:
   - Dhan API limit: 1 request per 3 seconds
   - Deduplication prevents duplicate calls
   - If rate limited, returns 429 status

3. Timezone:
   - All times calculated in Asia/Kolkata (IST, UTC+5:30)
   - Frontend should handle timezone conversion for display

4. Error Handling:
   - Invalid credentials: 400 Bad Request
   - Auth failure: 401 Unauthorized
   - Rate limited: 429 Too Many Requests
   - Service down: 503 Service Unavailable
   - Timeout: 503 Service Unavailable
